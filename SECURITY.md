# Reporting a security issue

Email **screamcode@gmail.com** with the app name, version, affected platform,
steps to reproduce and likely impact. Please report vulnerabilities privately;
do not put health data, household join codes, credentials or personal details in
public issues. Use synthetic data when possible.

Support is focused on the latest released version and current development branch.
There is no guaranteed response time or bug bounty. Fixes and any user action
needed will be documented in the affected app's release notes.

Each app's privacy policy is linked from https://screamxy.github.io/.
